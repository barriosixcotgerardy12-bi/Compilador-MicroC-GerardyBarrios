# Selectores de Color 
Es cuando en el codigo hay un color de formato en Visual Studio Code automaticamente pone un pequeño cuadrito de color al lado, Si haces clic en él se abre esa rueda de colores para que puedas cambiar el color visualmente sin escribir el código manualmente.

* #313244 — gris oscuro de los botones
* #cdd6f4 — blanco azulado del texto
* #a6e3a1 — verde de la consola
